# 拼豆图纸生成器

把一张图片变成拼豆图纸：自动配色到 Mard 221 色色卡，标好每一格的色号，并在图纸下方列出每种颜色要用多少颗豆子。

图片只在你自己的浏览器里处理，不会上传到任何地方。

## 怎么用

**1. 上传图片**

点左边的方框选一张图，JPG、PNG、WebP、GIF 都行。

**2. 调裁剪范围**

右边原图上会出现一个框，拖动框身移动位置，拖四个角改大小。默认框住整张图，想只做其中一部分就把框拖小。

下面的「保持裁剪框比例」打开时，图纸会按你框的形状来；关掉则再裁成正方形。

**3. 选板子**

- **52×52** — 2×2 块标准拼豆板，成品约 26cm 见方
- **78×78** — 3×3 块，约 39cm
- **104×104** — 4×4 块，约 52cm

板子越大格子越多，细节保留得越好，但豆子用量和拼的时间也成倍增加。

「画面占板比例」可以让图案不顶满板子，四周留出空边。

**4. 调简化程度**

这是最影响成品好看程度的一项。

直接把照片缩小配色，结果往往是天空、水面这种本该是一整片的地方被十几种相近的蓝色穿插着铺满 — 每一格单看都配得对，拼出来却是一片噪点，而且清单上会多出一堆只用 1、2 颗的颜色。

简化程度做两件事：先决定整张图最多能用多少种颜色，再把零星的单颗豆子并进周围的颜色里。往右拉，天空和水面会变成大片纯色，画面更像一张有意为之的卡通插画，颜色种类和采购成本也跟着降下来。

- **关闭** — 忠实还原，适合本来颜色就少的像素图、logo
- **轻度 / 中等** — 大多数照片和插画用这两档
- **较强 / 最强** — 大色块风格，或者你只想少买几种颜色

细节多的图更需要往右拉。

**5. 抠图（可选）**

打开后背景格子不放豆，做成镂空的形状。三种方式：

- **颜色泛洪** — 本地计算，从边缘往里吃掉颜色接近的部分。背景是纯色或平滑渐变时最好用，可以用「背景容差」微调
- **ML 人像** — 需要联网，识别照片里的人。背景杂乱时用这个
- **通用物体** — 需要联网，首次约下载 40MB。识别任意主体，适合玩偶、商品、动物

## 图纸怎么看

每一格里印着色号（比如 `C20`），格子的颜色就是那颗豆子的颜色。

- **细线** — 每一格
- **浅色粗线** — 每 26 格，是实体拼豆板的拼接缝
- **深色粗线 + 边上的数字** — 每 10 格一条，配合行号方便数格子。整板从 1 编到 52 / 78 / 104，和手里的拼豆板对得上

图纸正下方是用豆清单，按色号排序（字母升序、数字正序，A9 排在 A10 前面），标明每种颜色多少颗。导出的 PNG 自带这份清单，打印出来就能直接照着拼。

## 改单个格子

配色偶尔会挑错 — 眼睛的高光、细的描边这类地方最容易出问题。

在图纸上**拖拽框选**要改的格子，会进入编辑界面：

- 按住 <kbd>Shift</kbd> **拖拽**，把新框的区域**加进**已有选区
- 按住 <kbd>Shift</kbd> **点击**单个格子，**加进或移出**选区
- <kbd>Ctrl</kbd>/<kbd>Cmd</kbd> + <kbd>A</kbd> 选中整张图纸
- <kbd>Esc</kbd> 返回

所以选区不必是规规矩矩的方块 — 描边、曲线、散落的几颗都能一次选中改掉。

选好之后：

- 点右边的**候选色**直接换色。候选只列出这张图纸已经在用的颜色，所以换色不会让你多买一种豆子。排序按「这块区域的原图最像哪个颜色」
- 点左边**原图上的任意位置**，吸取那个像素的颜色应用到选区
- 点「不放豆」清空选区，做局部镂空

**镜像**：编辑界面上方有「水平镜像」「垂直镜像」，翻转当前选区（按选区的外接矩形算）。没有选中任何格子时翻转整张图纸。

改完的效果会立刻反映到图纸和清单上。

⚠️ 手动改的内容在你调整裁剪、板子、简化程度、抠图之后会被重新生成覆盖 — 所以把这些设置调满意了，最后再来修格子。

## 导出

- **导出图纸 PNG** — 完整图纸 + 用豆清单，一张图，可直接打印
- **导出清单 CSV** — 只有色号和颗数，方便照着采购

## 关于颜色

色卡来自 [pixel-beads.com](https://www.pixel-beads.com/zh/mard-bead-color-chart) 的 Mard 221 色标准色卡。屏幕上显示的是近似值，实体豆子的颜色会受光线和生产批次影响，可能和图纸上有些偏差。

配色用的是 CIE Lab 色彩空间，比直接比 RGB 更接近人眼对「像不像」的判断。
