# 拼豆图纸生成器

把一张图片变成拼豆图纸：自动配色到 Mard 221 色色卡，标好每一格的色号，并在图纸下方列出每种颜色要用多少颗豆子。

图片只在你自己的浏览器里处理，不会上传到任何地方。

## 怎么用

**1. 上传图片**

点左边的方框选一张图，JPG、PNG、WebP、GIF 都行。

**2. 调裁剪范围**

右边原图上会出现一个框，拖动框身移动位置，拖四个角改大小。默认框住整张图，想只做其中一部分就把框拖小。

下面的「保持裁剪框比例」打开时，图纸会按你框的形状来；关掉则再裁成正方形。

**3. 选板子**

- **52×52** — 2×2 块标准拼豆板，成品约 26cm 见方
- **78×78** — 3×3 块，约 39cm
- **104×104** — 4×4 块，约 52cm

也可以在「自定义」里填任意尺寸（16–160），**长宽可以不同**，比如 40×35。只填一个数就当正方形。

板子越大格子越多，细节保留得越好，但豆子用量和拼的时间也成倍增加。

「画面占板比例」可以让图案不顶满板子，四周留出空边。

**可用色卡**决定配色能从多少种豆子里挑：

- **标准 221 色** — A–H 与 M 系列，零售套装基本都是这个范围。默认选它，因为配出你买不到的颜色没有意义
- **完整 291 色** — 额外加上 P / Q / R / T / Y / ZG 六个扩展系列共 70 色。这些通常要单独买，确认手上有再开

开启扩展色后配色会更准（比如纯黄这类标准色卡里没有的颜色），代价是清单上可能出现你还没有的豆子。

### 像素画还原（可选）

如果你上传的本身就是一张像素画 —— 常见的是被放大过的小图，一个 32×32 的图标被存成了 512×512 —— 普通缩放会把原本干净的像素块重新平均、糊成一团。打开「按原始分辨率还原」会先**自动找回它原来的尺寸**，再按那个尺寸一格一像素地取色：每一格正好落在原图的一个像素块里，颜色照搬，不缩放也不平均。除了必须的「配到 Mard 色卡」之外，风格、卡通化、结构增强这些一律不参与 —— 目的就是还原原样。

原理是看行、列方向的颜色跳变。放大过的像素画，色块边界会在固定间隔上形成规则的高频尖峰，而块内部相邻的行、列只是同一批像素的副本、几乎没有差异。于是从最粗的网格往细里试各个「原始列数／行数」，第一个能把几乎全部跳变都收进网格边界、块内部又几乎不漏的那一档，就是原始分辨率本身（而不是它的整数倍）。这个判据同时把普通照片挡在外面 —— 照片"到处都是边"，任何比一半还粗的网格都会漏掉大量块内跳变，于是判不出周期，此时会提示你手动填。

检测不准时（比如原图是用非整数倍、带插值放大的），直接在框里填你知道的原始尺寸即可，填了就以你填的为准；想让它重新自动判断就点「重新检测」或清空输入框。

**抗水印**：如果这张像素画上盖了水印（比如你自己的图纸带着站点 logo，想还原成干净网格做库存记录），打开还原模式里的「抗水印」开关。它不再每格取正中那一个像素，而是**在更高分辨率上取样、每格按块内出现最多的颜色定色**：细线、半透明文字、小 logo 这类水印，在一个原始像素块里都是少数像素，会被多数票直接淘汰，露出底下的原色。局限也说清楚 —— **不透明地盖满整格的水印，那一格底下一个原始像素都没剩，任何本地算法都变不出来**，只能靠邻格去猜，而拼豆要的是准确色号，猜错不如不猜。所以它覆盖绝大多数常见水印，盖死整格的那种是物理下限。

抠图在这个模式下仍然可用；还原尺寸超过常规拼豆板（>160）时也能生成，只是清单里会标一句提醒。

**4. 选画面风格**

这是最影响成品好看程度的一步。三个预设会一次调好下面四项滑块，选完还能单独微调：

- **忠实** — 照片、像素图、logo，尽量还原原样
- **插画** — 油画、水彩、厚涂。压平区块、拉开明暗、提高彩度
- **海报** — 大色块强对比，颜色最少

为什么油画需要「插画」而不是「忠实」：把一幅画忠实地缩到几千格，得到的往往是一片灰泥。原因有两个，两个都不是配色配错了——

**一，明度被压扁了。** 很多画的实际明度范围本来就窄（莫奈《撑阳伞的女人》只占 L\* 25–76，最亮的云和最暗的伞面都远没到两端），缩小后这段窄范围还要再被量化，剩下的全是中间调。「明暗对比」按分位点把它拉回两端，天空才会变成"干净的浅蓝 + 纯白云"而不是一片灰。

**二，破碎笔触被平均成了灰。** 印象派并置的碎笔触，眼睛会**光学混合**成比物理平均值更鲜艳的颜色，而算法只会算平均。「色彩强度」是在补回这个差。

参考实体作品的做法也是如此——它们不是在忠实还原，而是重新解释成高对比的插画。

### 简化程度

直接把照片缩小配色，结果往往是天空、水面这种本该是一整片的地方被十几种相近的蓝色穿插着铺满 — 每一格单看都配得对，拼出来却是一片噪点，而且清单上会多出一堆只用 1、2 颗的颜色。

简化程度做两件事：先决定整张图最多能用多少种颜色，再把零星的单颗豆子并进周围的颜色里。往右拉，天空和水面会变成大片纯色，画面更像一张有意为之的卡通插画，颜色种类和采购成本也跟着降下来。

- **关闭** — 忠实还原，适合本来颜色就少的像素图、logo
- **轻度 / 中等** — 大多数照片和插画用这两档
- **较强 / 最强** — 大色块风格，或者你只想少买几种颜色

细节多的图更需要往右拉。

### 细节与色彩补偿

**板子越小、原图笔触越碎，这两项越重要。** 40×40 只有一千多格，直接缩小的结果往往是一片灰泥。

**结构增强**做的是**按区块分开处理**：把每个色块内部压平成一片，同时把区块之间的界限推得更利。

它不是普通的锐化。普通锐化无差别地放大所有高频，笔触噪点和真正的轮廓一起被放大，结果是更花而不是更清楚。这里用的是 Kuwahara 滤波：每个像素看它周围四个重叠的象限，取其中最均匀的那个的平均色。位于色块内部的像素四个象限都在同色区里，输出就是那块的平均色，整块被压平；骑在边界上的像素，跨界的象限方差大会被淘汰，它只会取到边界某一侧的颜色，边界因此被推向"非此即彼"而不是被抹匀。

这正是拼豆需要的：区块内部干净成一片，区块之间界限分明。对莫奈那种碎笔触尤其有效——一片由几十种蓝紫笔触组成的天空会被压成几块干净的色区，而不是在相邻格子间反复横跳。

**色彩强度**对付的是**颜色变灰**。这不是单纯调得好看——印象派这类并置笔触的画，眼睛会把相邻的碎笔触**光学混合**成比物理平均值更鲜艳的颜色，而算法只会算平均值。所以一片在你眼里是蓝的莫奈天空，算出来是灰的。配色前把彩度拉起来，才还原你实际看到的样子。

照片和像素图一般保持「原样」就行；油画、水彩、厚涂插画往上调到 ×1.4–×1.8 效果明显。

### 感知缩放（名画）

把一幅名画缩到几千格，普通做法是每格取平均，结果常常糊成一片中间调 —— 认不出是哪幅画。打开「感知缩放」会换一种降采样方式（Öztireli & Gross, SIGGRAPH 2015，基于 SSIM 的闭式解）：它先看每一格内部藏了多少细节，如果某格内部对比很强、又正好处在局部平坦的区域，就把这一格相对邻域的偏差**放大**，把平均本来会吃掉的局部对比重新顶出来。同样的格数下，脸、剪影、招牌笔触这些"一眼认出原画"的特征保留得更多。

它和招牌色的保留是两件事、各管一头：颜色这边由限色时的**特异度加权**负责 —— 离全图平均色越远的颜色（梵高的黄、莫奈的蓝，以及黑白高光这类极值）在减色时优先保住自己的色簇，不被平均掉。两者叠加，比单纯的「插画」预设更进一步。

代价是每次生成会略慢一点（多跑一遍逐格的邻域统计）。它主要给名画、复杂插画用；本来颜色就干净的像素图、logo 不需要开。开了它就不和「混色抖动」同时生效。

> 说到底这不是魔法：几千颗豆子承载不了一整幅画的全部信息，这是硬上限。感知缩放做的是在这个上限内，把有限的格子花在最能让人认出原画的地方。

### 混色抖动

默认关闭。打开后，颜色落在两颗豆子中间的**平坦区域**会用两色交替穿插来表现，靠眼睛在一定距离外把它们混起来，而不是硬倒向其中一边。大片渐变的天空、水面、草地纹理适合用它。

**只在被判为"纹理"的区域抖。** 判别用的是**结构张量**：区分边缘和纹理的关键不是梯度大不大（两者都大），而是**梯度有没有一致的方向**——轮廓上所有梯度都垂直于同一条边，草地里的梯度四面八方都有。计算格内梯度的两个特征值，方向一致的判为形体，杂乱的判为纹理。

所以草地会抖，天空、裙子这些平坦区和所有轮廓保持干净色块——也就是实体作品实际在做的事。

判别在**结构增强之前**做：结构增强本来就是为了压平纹理，在它之后再判断，草地早被抹平了。

用的是有序（Bayer）网格而不是误差扩散：误差扩散产生的是不规则游走的噪点，照着拼极其痛苦——你没法预期下一颗是什么。Bayer 是固定周期的网格，拼起来有规律，看着也更像有意为之的编织纹。

⚠️ 判别不是完美的，实测数据摆在这里：在莫奈《撑阳伞的女人》上，每格纹理度的中位数是**草地 0.60、天空 0.26、裙子内部 0.14**，方向是对的，但分布有重叠——天空的 p90 到 0.79，因为云的边缘本身就是真结构。门槛取 0.7 时草地有 41% 的格子会抖、天空误抖 14%；取 0.8 时是 32% / 10%。

所以滑块往右拉纹理更足，但天空也更容易长麻子。默认关闭，建议先把其它项调好再试着开一点。印象派这类"哪儿都是笔触"的原作是最难的情形；照片和插画的纹理区通常干净得多。

### 小板子上怎么保住主体

40×40 这种尺寸格子有限，按影响从大到小：

1. **裁得紧一点** — 最有效的一招。把裁剪框收到主体上，别让背景白白占掉一半格子
2. **色彩强度往上调** — 见上
3. **结构增强开到适中或较强**
4. **简化程度别太低** — 格子本来就少，颜色再多只会让每种色都碎成几颗，反而看不清形状。中等或较强通常比"关闭"更像原图

**5. 抠图（可选）**

打开后背景格子不放豆，做成镂空的形状。三种方式：

- **颜色泛洪** — 本地计算，从边缘往里吃掉颜色接近的部分。背景是纯色或平滑渐变时最好用，可以用「背景容差」微调
- **ML 人像** — 需要联网，识别照片里的人。背景杂乱时用这个
- **通用物体** — 需要联网，首次约下载 40MB。识别任意主体，适合玩偶、商品、动物

## 图纸怎么看

每一格里印着色号（比如 `C20`），格子的颜色就是那颗豆子的颜色。

- **细线** — 每一格
- **浅色粗线** — 每 26 格，是实体拼豆板的拼接缝
- **深色粗线 + 边上的数字** — 每 10 格一条，配合行号方便数格子。整板从 1 连续编号，和手里的拼豆板对得上

两种粗线都是**居中**摆的：除不尽时余数平均分到两侧，而不是从一边开始排、把零头全甩到另一边。这样无论你从哪个角开始数，落到的都是同一批线。

比如 40×40：一块 26 格的实体板放不满，接缝线画在第 7 和第 33 格，两边各余 7 格——对应你实际拼的时候板子摆在中间的样子。板子小于 26 格时就不画接缝线了。

图纸正下方是用豆清单，按色号排序（字母升序、数字正序，A9 排在 A10 前面），标明每种颜色多少颗。导出的 PNG 自带这份清单，打印出来就能直接照着拼。

## 一次拼一个颜色

实际拼的时候通常是倒出一种颜色的豆子，然后在图纸上找齐所有该放的位置。

**点图纸上任意一格**，或者**点右侧用豆清单里的一行**，就会高亮那个颜色：其余格子淡出，该颜色的格子描上橙框，并且**每一行内从左到右标 1、2、3……，下一行重新从 1 开始**。

所以放豆的时候不用一格格数着找，看行号定位到某一行，然后数到第几颗就行。上方还会显示这个颜色一共多少颗、分布在几行、单行最多几颗。

再点一次同一个颜色，或者点「取消高亮」，就恢复正常显示。

导出的 PNG 始终是完整图纸，不会带上淡化效果。

## 豆子库存

记录手上每个色号还剩多少颗，生成图纸时就能直接看出缺什么。

点用豆清单上方的**「管理库存」**录入。默认只列出跟当前图纸相关的色号（这张图用到的 + 你已经登记过的），不会一上来就摊开两百多个色号让你翻。

### 加减单个颜色

真正会发生在库存上的事只有两件：用掉了一些、买了一些。都是加减，不该让你自己算"原来 412 颗，用掉 37 颗，所以填 375"。

**每一行右边都有 − 和 +**，直接点就能加减那个色号，加减的幅度由面板顶部的「每次加减 N 颗」决定。

想连续调同一个颜色的话，点一下那一行选中它，顶部会显示它的现有数量和本图需求，用那里的「− 用掉 / + 补货」更顺手（按回车等于补货）。改完会回显 `A1：100 → 70 颗`，不用自己核对。

减过头不会变成负数，会停在 0 并明确告诉你。

每行中间的输入框是**绝对值**——重新数过一遍之后直接填准确数字用它。

> 库存面板里的选中，和图纸上的颜色高亮是两回事，互不影响。前者是"我在改哪一行"，后者是"这颗豆子在图纸的哪些位置"。

### 批量填数字

一个个填两百多个色号是不现实的，所以有批量操作。填一个数字，然后：

- **全部设为** — 把列出的色号统统改成这个数。比如每种颜色都买了一包、一包约 500 颗，填 500 点一下就行
- **全部各加** — 在各自现有数量上加这个数。补货时用，各色号原来的差异会保留（10/3/5 各加 7 → 17/10/12）
- **按当前图纸补齐** — 只把不够的补到刚好够，富余的不动

**作用范围就是下方列表里显示的色号**。默认只列出跟当前图纸相关的（这张图用到的 + 已登记的）；想覆盖整套色卡，先点「显示全部色号」再批量。按钮上方那行小字会实时告诉你当前会影响几个色号。

批量操作会先弹确认，避免手滑把辛苦填的数据冲掉。

### 备份

**导出 CSV 备份 / 导入 CSV**，格式是 `色号,库存` 两列。

登记之后，用豆清单会多一列「库存」，不够的行标红并写明差多少颗，上方还有一句汇总。

**表头可以点着排序**：「色号」「需要」「库存」都能点，再点一次翻转正序／倒序，当前排序列会带一个 ▲▼ 箭头。

- 点「需要」→ 先按用量从多到少，一眼看出这张图主要吃哪几种颜色
- 点「库存」→ 正序时最缺的排最前，照着去补货

合计行始终固定在最后，不参与排序。另外**图纸下方打印的清单和导出的 CSV 始终按色号排**，不受这里的排序影响——那两个是拿在手上照着找豆子用的，顺序得稳定。

拼完一张图，点**「✓ 拼完了，扣减库存」**，会先确认再从库存里扣掉这张图的用量。旁边的**「撤销上次扣减」**可以还原——它还回的是当时实际扣掉的数量，所以即使那次扣的时候某个颜色本来就不够，撤销也不会凭空多出豆子。

⚠️ 默认情况下库存只存在这台电脑的浏览器里。换浏览器、换设备、或者清理浏览器数据都会丢，所以记得偶尔导出 CSV 备份。

### 跨设备同步（可选）

面板顶部「数据存在哪里」会直接告诉你当前状态：是只在这台设备，还是已经连上了云端、用的哪个档案。

想让几个人各自的库存跨设备可用，顺序是：

1. **先部署一个同步服务器**（一次性，全程点网页不用装东西）。方法见 `worker/README.md`。免费额度内不花钱
2. 管理员在 KV 里给每个人加一条记录，分给他一串**专属口令**
3. 各人在「设置跨设备同步」里填两样：**服务器地址** 和 **自己的口令**
4. 点「保存并测试连接」，成功会显示「服务器认出你是「小李」」
5. 第一次用点「上传到云端」；换了设备点「从云端拉取」

**一人一个口令，口令本身就是身份**，不用填名字。服务端根据口令决定这次请求属于谁，所以你只能读写自己的库存，读不到也写不坏别人的。

**没做第 1 步的话，这里没有任何东西可连** —— 库存会一直只存在本机，那样也完全能用，只是记得导出 CSV 备份。

扣减只在你点那个按钮时发生——导出图纸、改设置都不会动库存。

## 改单个格子

配色偶尔会挑错 — 眼睛的高光、细的描边这类地方最容易出问题。

进入编辑界面有三种方式：**双击**任意一格、在图纸上**拖拽框选**一片格子、或者点图纸右上角的**「编辑格子」**按钮。（单击一格是高亮颜色，见上一节。）

编辑界面里：

- 按住 <kbd>Shift</kbd> **拖拽**，把新框的区域**加进**已有选区
- 按住 <kbd>Shift</kbd> **点击**单个格子，**加进或移出**选区
- <kbd>Ctrl</kbd>/<kbd>Cmd</kbd> + <kbd>A</kbd> 选中整张图纸
- <kbd>Esc</kbd> 返回

图纸太密看不清就放大：编辑界面右上角的 <kbd>+</kbd> <kbd>−</kbd> 按钮、键盘 <kbd>+</kbd> <kbd>−</kbd>、或者按住 <kbd>Ctrl</kbd>/<kbd>⌘</kbd> 滚滚轮。<kbd>0</kbd> 或「适应宽度」回到整屏。滚轮缩放以光标为中心，所以放大时正在看的地方不会跑掉。

所以选区不必是规规矩矩的方块 — 描边、曲线、散落的几颗都能一次选中改掉。

选好之后：

- 点右边的**候选色**直接换色。候选只列出这张图纸已经在用的颜色，所以换色不会让你多买一种豆子。排序按「这块区域的原图最像哪个颜色」
- 点左边**原图上的任意位置**，吸取那个像素的颜色应用到选区
- 点「不放豆」清空选区，做局部镂空

**镜像**：编辑界面上方有「水平镜像」「垂直镜像」，翻转当前选区（按选区的外接矩形算）。没有选中任何格子时翻转整张图纸。

改完的效果会立刻反映到图纸和清单上。

⚠️ 手动改的内容在你调整裁剪、板子、简化程度、抠图之后会被重新生成覆盖 — 所以把这些设置调满意了，最后再来修格子。

## 导出

- **导出图纸 PNG** — 完整图纸 + 用豆清单，一张图，可直接打印
- **导出清单 CSV** — 只有色号和颗数，方便照着采购

## 关于颜色

色卡来自 [pixel-beads.com](https://www.pixel-beads.com/zh/mard-bead-color-chart)：标准 221 色（A–H、M）加扩展 70 色（P/Q/R/T/Y/ZG），共 291 色。屏幕上显示的是近似值，实体豆子的颜色会受光线和生产批次影响，可能和图纸上有些偏差。

配色用的是 CIE Lab 色彩空间，比直接比 RGB 更接近人眼对「像不像」的判断。
